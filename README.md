## 🛒 4. Funcionalidades do Carrinho e Interatividade

- **Carrinho Lateral (Offcanvas):** Lista dinâmica de itens com fotos em miniatura, ajuste de quantidades e remoção.
- **Cálculo Automático em Tempo Real:** Subtotal e total recalculados instantaneamente.
- **Edição de Preços em Tempo Real:** Clique no lápis ao lado de qualquer preço para atualizá-lo com recálculo automático.
- **Persistência com LocalStorage:** O pedido e as alterações de preços permanecem salvos entre recarregamentos.
- **Finalização de Pedido com WhatsApp:** Monta o pedido formatado com o padrão **BOUDALAIRE** pronto para envio com 1 clique.
- **Mobile First:** Botão flutuante (FAB) para fácil acesso no celular.
